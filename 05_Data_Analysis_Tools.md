# Data Analysis Tools

Different tools are used at different stages of the Data Analysis process.

## 1. Microsoft Excel

Excel is widely used for:

- Data cleaning
- Calculations
- Pivot Tables
- Charts
- Reporting
- Basic dashboards

## 2. SQL

SQL is used to work with data stored in databases.

Common SQL tasks include:

- Retrieving data
- Filtering records
- Joining tables
- Aggregating data
- Creating reports

## 3. Power BI

Power BI is a Business Intelligence and Data Visualization tool.

It is used to:

- Connect to data
- Transform data
- Build data models
- Create dashboards
- Share insights

## 4. Python

Python is useful for:

- Data cleaning
- Data analysis
- Automation
- Statistical analysis
- Data visualization

Important libraries:

- Pandas
- NumPy
- Matplotlib

## 5. Statistics

Basic statistics help Data Analysts understand data.

Important concepts include:

- Mean
- Median
- Mode
- Percentage
- Variance
- Standard Deviation
- Correlation

## 6. Data Visualization

Data visualization helps communicate insights effectively.

Common charts:

- Bar Chart
- Line Chart
- Pie Chart
- Scatter Plot
- Histogram
- Map

## Data Analysis Tool Workflow

```text
Excel / CSV / Database
          ↓
       SQL
          ↓
    Data Cleaning
          ↓
      Analysis
          ↓
      Power BI
          ↓
     Dashboard
          ↓
     Business Insight
```
