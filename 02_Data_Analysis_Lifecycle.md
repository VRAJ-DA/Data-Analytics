# Data Analysis Lifecycle

The Data Analysis Lifecycle is a step-by-step process used to convert raw data into useful business insights.

## 1. Define the Problem

First, understand the business problem and define the questions that need to be answered.

### Example

Business Question:

> Why have monthly sales decreased?

## 2. Collect Data

Data can be collected from different sources:

- Excel files
- CSV files
- Databases
- APIs
- Business applications
- Surveys

## 3. Clean the Data

Raw data may contain:

- Missing values
- Duplicate records
- Incorrect formats
- Spelling mistakes
- Invalid values

Data cleaning improves the quality and reliability of the analysis.

## 4. Explore the Data

In this stage, we look for:

- Trends
- Patterns
- Outliers
- Relationships
- Distribution of data

## 5. Analyze the Data

Analytical techniques are used to answer business questions.

Examples:

- Aggregation
- Filtering
- Grouping
- Calculations
- SQL queries
- Statistical analysis

## 6. Visualize the Data

Charts and dashboards make insights easier to understand.

Common visualizations:

- Bar Chart
- Line Chart
- Pie Chart
- Map
- KPI Cards
- Tables

## 7. Communicate Insights

The final step is to explain the findings clearly to stakeholders.

A good insight should explain:

- What happened?
- Why did it happen?
- What should be done next?

## Complete Flow

```text
Business Problem
       ↓
Data Collection
       ↓
Data Cleaning
       ↓
Data Exploration
       ↓
Data Analysis
       ↓
Data Visualization
       ↓
Business Insights
       ↓
Decision Making
```
