# What is Data Analysis?

## Definition

Data Analysis is the process of collecting, cleaning, transforming, exploring, and interpreting data to discover useful insights and support better decision-making.

In simple words:

> Data Analysis means converting raw data into meaningful information.

## Example

Suppose a company has sales data containing:

- Order ID
- Customer Name
- Product
- Quantity
- Sales
- Region
- Date

A Data Analyst can analyze this data to answer questions such as:

- Which product sells the most?
- Which region generates the highest sales?
- Which month has the highest revenue?
- Who are the most valuable customers?
- Why are sales decreasing?

## Data Analysis Process

1. Collect the data
2. Clean the data
3. Explore the data
4. Analyze the data
5. Visualize the results
6. Communicate insights

## Why is Data Analysis Important?

Data Analysis helps organizations:

- Make data-driven decisions
- Understand business performance
- Identify trends and patterns
- Find problems and opportunities
- Improve efficiency
- Increase revenue

## Key Idea

A Data Analyst does not only work with numbers.

A Data Analyst asks:

> What happened?
>
> Why did it happen?
>
> What can we learn from it?
>
> What action should be taken?
